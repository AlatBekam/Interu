INTERU — CYBER OPERATIONS
RUY Cybersecurity Team
Versi aplikasi: 1.4.0 | Windows x64 | 14 November 2026

APA ITU INTERU
Interu adalah aplikasi desktop untuk pengujian keamanan jaringan dan web
pada target yang diizinkan. Otomasi memakai rule engine dan probe deterministik.
Tidak ada model AI atau layanan AI di alur pemindaian.

PAKAI APLIKASI
1. Installer: release\Interu-Setup-1.4.0.exe
   Portabel: release\Interu-Portable-1.4.0.exe
2. Tambahkan target berizin ke Scope. Scope kosong menolak operasi jaringan
   aktif ke target.
3. Buka Pentest Automation untuk crawl, pemeriksaan pasif, probe parameter,
   dan template aktif dalam satu run dengan batas request/waktu yang dapat
   diatur. Temuan dapat dibuka di Operations > Vulnerabilities.

FITUR YANG TERSEDIA
- Web Security Suite: proxy HTTP/HTTPS dan intercept, browser bawaan,
  Repeater, Intruder, Site Map, Crawler, Active Scan, Decoder, Comparer,
  dan Sequencer.
- Active Scan: probe GET terbatas untuk sinyal SQLi, XSS, LFI, XXE, SSTI,
  RCE, SSRF, IDOR, akses sensitif, dan CSRF. Kandidat tetap diberi label
  suspected bila dampaknya belum terbukti.
- Rule Engine: 808 template data (28 port/banner, 47 HTTP pasif, 733 HTTP
  aktif), matcher DSL, extractor, baseline soft-404, korelasi, dan bukti.
  Detektor field password pada JSON daftar pengguna ada di luar hitungan
  template. Isi field password tidak disimpan pada objek temuannya.
  Temuan terkonfirmasi dapat menampilkan saran verifikasi dan perbaikan
  melalui advisor Attack/Defense.
- Network Scanner: TCP connect scan dan pembacaan banner.
- Exposure Monitor dan Vulnerabilities: aktivitas/temuan lokal serta detail
  bukti request/response. Flag lab dapat dilihat dari detail temuan.
- Login dapat dilakukan manual lewat browser bawaan Proxy. Header Cookie
  dari request setelah login dapat ditempel ke Authenticated scan untuk
  Crawler, Active Scan, Rule Engine aktif, dan Pentest Automation. Header
  sesi disimpan dalam memori proses utama selama aplikasi berjalan.
- Automation memiliki opsi Explore browser + run: membuka browser lewat
  Proxy, menjelajah halaman satu origin, mencatat form login/register,
  lalu memakai URL hasilnya sebagai seed scanner.
- Opsi Explore + create test account + run membuat identitas sementara
  sendiri, mencoba form registrasi POST dan login pada origin yang sama,
  kemudian memakai cookie browser yang berubah untuk request scanner.
  Tidak perlu mengetik kredensial; hasil login tidak diklaim hanya karena
  cookie ada. Form CAPTCHA/MFA/verifikasi email/SSO bisa menghambat alur.
- Antarmuka menyediakan tema Dark dan Light. Proxy meneruskan traffic di
  luar Scope tanpa inspeksi; HTTPS di luar Scope tidak didekripsi.

LOGIN MANUAL, LALU SCAN DENGAN SESI
1. Masukkan host target ke Scope. Jalankan Proxy, pilih Open Browser, dan
   login dengan akun uji pada situs target.
2. Di riwayat Proxy, buka request ke halaman yang memerlukan login.
   Salin baris Cookie: ... dari REQUEST, bukan Set-Cookie dari response.
3. Di panel Authenticated scan, isi Credential origin yang tepat
   (protokol, host, port), tempel baris Cookie: ... di Headers, lalu klik
   Apply credentials. Authorization: Bearer ... juga didukung.
4. Jalankan Crawler, Active Scan, Rule Engine active checks, atau Pentest
   Automation. Header dipakai hanya pada origin yang sama dan dalam Scope.
5. Jika session expired, login ulang, tempel header baru, klik Apply
   credentials, lalu Refresh sebelum menjalankan ulang scan.

Pada alur manual, cookie masih disalin dari Proxy. Pada opsi akun uji
otomatis, cookie dihubungkan ke scanner dalam proses utama.
Pemindaian memakai hak akses akun yang dipakai login; gunakan akun uji.

PERUBAHAN VERSI 1.4.0
- Browser Chromium lewat Proxy menjelajah maksimal 12 halaman GET satu
  origin dengan jeda minimum 500 ms dan memasukkan URL hasil ke Automation.
- Form login/register dicatat sebagai permukaan; opsi akun uji hanya
  mencoba form POST yang sesuai dan memakai identitas acak.
- Sesi lama dibersihkan sebelum percobaan akun baru. Kata sandi sementara
  dan nilai cookie tidak dikembalikan ke UI Automation.
- Registrasi/login dapat membuat data akun pada target. Gunakan hanya jika
  aturan target mengizinkan pembuatan akun uji otomatis.

PERUBAHAN VERSI 1.3.0
- Crawler lebih selektif pada tautan HTML dan JavaScript; menemukan rute
  GET dari OpenAPI JSON/YAML dan memprioritaskan URL berparameter.
- Deteksi SQLi SQLite memakai baseline, input petik, dan kontrol penyeimbang.
- Probe IDOR tidak menilai perubahan ID objek publik sebagai bypass akses.
- Cookie infrastruktur dikenal diabaikan dalam pemeriksaan cookie sesi;
  CORS wildcard dicatat sebagai informasi tanpa bukti paparan data.
- Path GET yang dapat mengubah state, seperti /createdb dan /start_over,
  dilewati crawler.

PENGUJIAN YANG SUDAH DILAKUKAN
- Typecheck dan 300 tes otomatis berjalan lulus pada sumber 1.4.0.
- Tes akun lokal membuktikan browser membuat akun, login, dan request
  scanner membaca halaman privat; kata sandi tidak muncul di UI.
  Bukti: audit\browser-account-verification.json.
- Pada lab RUY Docker, paket 1.3.0 menampilkan 150/150 kasus masing-masing
  melalui Active Scan, Rule Engine, dan Pentest Automation. Detail flag 1
  dan 150 dibuka lewat antarmuka. Bukti: audit\lab-ui-verification.json.
- Pentest Automation diuji terbatas tanpa header sesi login pada 10 target
  latihan independen: 7 online dan 3 Docker lokal.
  Bukti: audit\multi-target-benchmark.json.
  Run itu mencatat 3 sinyal SQLi MySQL dan 1 disclosure file di DVWA online,
  serta 1 sinyal SQLi SQLite pada Juice Shop lokal. Run tambahan VAmPI
  menemukan respons JSON dengan field password tanpa menyimpan nilainya:
  audit\multi-target-single.json. Kandidat XSS Altoro tetap kandidat.
- Installer 1.4.0 sudah terpasang; pemeriksaan aplikasi terpasang tersimpan
  di audit\installed-verification.json. Versi aplikasi dan layar Automation
  berhasil diperiksa.
- Run browser pada 10 target tersimpan di audit\ten-browser-benchmark.json.
  Tidak ada form registrasi yang cocok dalam run tersebut dan jumlah temuan
  inti terkonfirmasi tidak bertambah. Rangkuman ada di
  LAPORAN-PERBANDINGAN-10-TARGET-1.4.0.md.

BATAS YANG PERLU DIKETAHUI
- Lab 150 kasus dibuat khusus sebagai target uji Interu. Hasilnya tidak
  menyatakan cakupan atau akurasi pada semua aplikasi nyata.
- Belum ada ground truth lengkap per endpoint untuk menghitung tingkat
  kesalahan temuan. Header/cookie yang teramati tidak otomatis berarti
  dampak keamanan telah dibuktikan.
- Uji 10 target tanpa sesi tidak mengukur kemampuan pemindaian di balik
  login. Interu mendukung header sesi manual seperti dijelaskan di atas.
- Browser discovery merender JavaScript, tetapi probe kerentanan otomatis
  berfokus pada GET. Alur POST/GraphQL dan logika SPA kompleks bisa terlewat.
- Paket installer belum ditandatangani dengan sertifikat penerbit kode.

PENGEMBANGAN DARI SUMBER
Windows x64, Node.js 20+, npm. Jalankan di folder proyek:
  npm install
  npm run typecheck
  npm test
  npm run dist
Output installer/portabel ada di release/. Kode ada di src/main,
src/shared, src/preload, dan src/renderer. Lab lokal ada di lab/.

Gunakan hanya pada sistem sendiri atau target yang jelas mengizinkan
pengujian. Atur laju, modul, dan batas target sesuai aturan pemiliknya.
