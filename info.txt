1. APA INI
--------------------------------------------------------------------------------
Interu adalah PLATFORM OPERASI SIBER OFENSIF all-in-one buatan Indonesia,
berbentuk aplikasi DESKTOP WINDOWS (Electron + React + TypeScript).

Satu aplikasi menggabungkan:
  - Web Security Suite gaya Burp Suite (Proxy, Repeater, Intruder, Crawler,
    Active Scan, dll)
  - Modul Operations (Network Scanner, Vulnerabilities, Exposure Monitor)
  - Rule Engine (Detection)
Dilengkapi SCOPE / AUTHORIZATION (legal-by-design): fitur "Live" hanya boleh
menyerang host yang didaftarkan ke Scope (yang kita punya izinnya).

Identitas visual: industrial, datar (flat), padat; satu warna aksen, tema Dark + Light
(warna lewat token peran, lihat docs/092_panduan-tampilan.md).

PENTING: tool pentest ini HANYA untuk target yang kita miliki izinnya
(lab sendiri / server berizin). Tidak ada mode simulasi: semua halaman LIVE.

3. STACK & CARA MENJALANKAN
--------------------------------------------------------------------------------
Stack  : Electron 33 + React 18 + TypeScript + Vite (electron-vite),
         packaging pakai electron-builder, MITM pakai node-forge.

A) CUMA MAU PAKAI (tanpa ngoding):
   - Jalankan file installer: Interu-Setup-1.0.0.exe  (atau Portable .exe)
   - Kalau SmartScreen muncul -> More info -> Run anyway (wajar, belum signed)
   - Setelah install, cari "Interu" di pencarian Windows / shortcut Desktop

B) MAU NGODING / NGEMBANGIN BARENG:
   1. Install Node.js LTS (v20+; dibangun pakai v24) dari nodejs.org
   2. Extract source (TANPA folder: node_modules, out, release)
   3. Buka terminal di folder project, jalankan:
        npm install        -> restore semua dependency
        npm run dev         -> mode development (hot reload)
        npm run build       -> build produksi ke folder out/
        npm run dist        -> build + bikin installer .exe ke folder release/
   - Wajib ikutkan package-lock.json biar versi sama persis.
   - Kalau 'npm run dist' error 'Cannot create symbolic link ... winCodeSign':
     lihat README (ada solusi pre-extract / nyalain Developer Mode).

Struktur penting:
  src/main/        -> proses Electron (window, proxy, MITM CA, HTTP, scanner)
    index.ts       -> window + semua IPC (termasuk ruy:scan:tcp)
    proxy.ts       -> forward proxy + HTTPS MITM
    ca.ts          -> root CA + cert per-host (untuk MITM)
    http.ts        -> HTTP client asli (Repeater/Intruder/Target live)
    scan.ts        -> TCP connect scanner ASLI (Node net) + banner grab  (BARU)
  src/preload/     -> jembatan aman renderer <-> main (http, proxy, scan)
  src/shared/      -> dipakai bareng main & renderer:
    http.ts        -> tipe HTTP + scope gate host (hostInScope)
    proxy.ts       -> tipe event proxy
    scan.ts        -> parse target CIDR/range, daftar port, ipInScope
    rules.ts       -> Rule Engine: 408 template + matcher + extractor +
                      interpolasi + baseline + korelasi + CVE
    dsl.ts         -> evaluator ekspresi DSL aman (tanpa eval)             (BARU)
    crawl.ts       -> crawler BFS: temukan link/form/endpoint fetch()      (BARU)
    webvuln.ts     -> oracle SQLi/XSS/IDOR/access/CSRF (FP-safe)           (BARU)
    advice.ts      -> advisor Attack/Defense per temuan                    (BARU)
  src/renderer/src/
    pages/web/     -> Web Security Suite (Target, Crawler, ActiveScan, Proxy,
                      Repeater, Intruder, Decoder, Comparer, Sequencer)
    pages/         -> NetworkScanner (REAL), RuleEngine, Vulnerabilities,
                      ThreatMonitor (Exposure Monitor), Settings
    components/    -> Sidebar, TopBar, ThemeToggle, ScopeBar, ContextMenu,
                      CopyButton, Crest, icons, ui
    data/          -> burp.ts (hanya PAYLOAD_SETS Intruder)
    lib/           -> severity.ts (Severity, SEVERITY_ORDER, severityPill)
    store/         -> store.ts (settings+persist), transfer.ts (send-to bus),
                      findings.ts (store temuan Rule Engine)               (BARU)
    lib/http.ts    -> parse raw request, curl, sendLive


4. STATUS PER-MODUL (semua LIVE)
--------------------------------------------------------------------------------
== WEB SECURITY SUITE (SELESAI / REAL) ==
  [DONE] Proxy        : Forward proxy ASLI + HTTPS MITM (dekripsi TLS).
                        - Start di 127.0.0.1:8080, Intercept Forward/Drop/Edit
                        - Open Browser (browser asli lewat proxy, auto-trust CA)
                        - Export CA (buat browser eksternal)
                        - HTTP History live + Inspector
                        - Klik kanan baris: Send to Repeater/Intruder, Copy URL,
                          Copy request, Copy response, Copy as curl, Inspect
                        - Inspector request/response bisa diseleksi + tombol Copy
  [DONE] Repeater     : kirim HTTP asli (awal: GET / ke localhost:3000)
  [DONE] Intruder     : serang payload asli (template POST /api/login)
  [DONE] Target/Site  : Live content discovery (fuzzing path asli)
                        + klik kanan: Send to Repeater/Intruder
  [DONE] Decoder      : URL/Base64/Hex/HTML/ASCII encode-decode (offline, REAL)
  [DONE] Comparer     : Diff dua pane (LCS, offline, REAL; mulai dengan pane kosong)
  [DONE] Sequencer    : Analisa entropi token yang di-paste operator (satu per baris)
  [DONE] Crawler      : autopilot BFS crawler (scope-gated) — petakan page,
                        link, form, endpoint inline fetch(); passive per page
                        (auto-detect hanya pada 2xx non-binary -> anti-FP)   (BARU)
  [DONE] Active Scan  : autopilot scanner vuln (scope-gated), oracle FP-safe:
                        SQLi error-based + reflected XSS -> Confirmed;
                        IDOR / access-control / CSRF -> Suspected (tak auto)  (BARU)
  [DONE] Scope gate   : semua Live digerbang host berizin

== OPERATIONS (REAL) ==
  [DONE] Network Scanner  : TCP connect scan ASLI (Node net), scope-gated.
                            - Target IP / CIDR / range / list, parse otomatis
                            - Profile Quick/Standard/Deep (deep = banner/versi)
                            - open/closed/filtered nyata, progress streaming,
                              bisa di-Stop (cancel); hanya Live (bridge hilang
                              -> "Scanner bridge unavailable", Run Scan nonaktif)
                            - hasil otomatis difeed ke Rule Engine
  [DONE] Vulnerabilities  : temuan Rule Engine (Confirmed/Suspected + bukti + CVE),
                            hanya tampilan Live
  [DONE] Exposure Monitor : feed temuan & aktivitas nyata (bukan IDS)

(Dashboard, Firewall Rules, dan Reports dihapus karena 100% data palsu.
 Ide laporan dari temuan asli & ekspor firewall tercatat sebagai halaman BARU
 di roadmap.)

== DETECTION (NUCLEI-GRADE) ==
  [DONE] Rule Engine      : engine ala-Nuclei, template sebagai DATA (408 template:
                            28 port/banner, 47 HTTP pasif, 333 HTTP aktif).
                            - Matcher: status/word/regex/time/port/service + DSL
                              (evaluator ekspresi AMAN tanpa eval), kombinasi and/or,
                              negative; EXTRACTOR (versi/token/username ke field);
                              interpolasi {{BaseURL}} di request
                            - Pasif: makan hasil Network Scanner (port/banner->CVE)
                              + respons Proxy (header hilang, cookie, CORS, secret
                              leak, error SQL, dll)
                            - Aktif (oracle): 333 GET baca-saja (/.git/config, /.env,
                              backup, actuator, panel, dll) scope-gated -> Confirmed
                            - Anti-FP: baseline soft-404 (catch-all 2xx -> demote),
                              tiap probe WAJIB penanda konten, korelasi group
                              (confirmed menggeser suspected), guard host mati
                            - Keyakinan jujur: Confirmed (teramati) vs Suspected
                            - Bukti lengkap: request/response + extracted per temuan
                            - ADVISOR ATTACK/DEFENSE per temuan confirmed:
                              * Defense = langkah patching + snippet config siap-salin
                                + tombol Re-test fix (jalankan ulang oracle)
                              * Attack = verify (baca-saja, nol FP) / operator (payload
                                disiapkan, Send to Repeater/Intruder) / info (PoC lokal)
                            - Halaman Detection: library template + active checks
                            - Diuji: 160 tes (vitest) rules/dsl/advice/crawl/
                              webvuln/scope
                            -> TODO: oracle boolean/time/OOB, template eksternal
                               YAML/JSON, Attack Path Graph

6. CATATAN PENTING
--------------------------------------------------------------------------------
  - Installer belum DI-SIGN -> SmartScreen muncul sekali, klik "Run anyway".
    Antivirus kadang curiga (wajar untuk tool proxy/MITM) -> whitelist.
  - Proxy dengerin di 127.0.0.1 saja. Saat Start/Open Browser, Windows Firewall
    bisa minta izin -> Allow.
  - Semua modul LIVE (nembak target asli) WAJIB isi Scope dulu. Tanpa itu ditolak.
  - Open Browser: kalau Intercept ON, halaman "nahan" nunggu di-Forward
    (app otomatis maju minta Forward). Kalau mau browsing santai, matikan
    Intercept dulu.
  - HTTPS di browser eksternal butuh "Export CA" lalu di-trust di OS/browser.
    Open Browser bawaan Interu sudah auto-trust (langsung kebaca).
  - Tidak ada data demo/mock. Settings -> Local data -> Reset local data menghapus
    data lokal (scope, temuan, pengaturan).
