1. APA INI
--------------------------------------------------------------------------------
Interu adalah PLATFORM OPERASI SIBER OFENSIF all-in-one buatan Indonesia,
berbentuk aplikasi DESKTOP WINDOWS (Electron + React + TypeScript).

Satu aplikasi menggabungkan:
  - Web Security Suite gaya Burp Suite (Proxy, Repeater, Intruder, dll)
  - Modul Operations (Scanner, Vulnerabilities, Threat Monitor, Firewall)
  - Reporting
Dilengkapi SCOPE / AUTHORIZATION (legal-by-design): fitur "Live" hanya boleh
menyerang host yang didaftarkan ke Scope (yang kita punya izinnya).

Identitas visual: "Dark Kingdom" (hitam obsidian + perak + navy) + mode Light.

PENTING: tool pentest ini HANYA untuk target yang kita miliki izinnya
(lab sendiri / server berizin). Ada juga mode Simulation untuk latihan aman.

3. STACK & CARA MENJALANKAN
--------------------------------------------------------------------------------
Stack  : Electron 33 + React 18 + TypeScript + Vite (electron-vite),
         packaging pakai electron-builder, MITM pakai node-forge.

A) CUMA MAU PAKAI (tanpa ngoding):
   - Jalankan file installer: Interu-Setup-1.0.0.exe  (atau Portable .exe)
   - Kalau SmartScreen muncul -> More info -> Run anyway (wajar, belum signed)
   - Setelah install, cari "Interu" di pencarian Windows / shortcut Desktop

B) MAU NGODING / NGEMBANGIN BARENG:
   1. Install Node.js LTS (v20+; dibangun pakai v24) dari nodejs.org
   2. Extract source (TANPA folder: node_modules, out, release)
   3. Buka terminal di folder project, jalankan:
        npm install        -> restore semua dependency
        npm run dev         -> mode development (hot reload)
        npm run build       -> build produksi ke folder out/
        npm run dist        -> build + bikin installer .exe ke folder release/
   - Wajib ikutkan package-lock.json biar versi sama persis.
   - Kalau 'npm run dist' error 'Cannot create symbolic link ... winCodeSign':
     lihat README (ada solusi pre-extract / nyalain Developer Mode).

Struktur penting:
  src/main/        -> proses Electron (window, proxy, MITM CA, HTTP, scanner)
    index.ts       -> window + semua IPC (termasuk ruy:scan:tcp)
    proxy.ts       -> forward proxy + HTTPS MITM
    ca.ts          -> root CA + cert per-host (untuk MITM)
    http.ts        -> HTTP client asli (Repeater/Intruder/Target live)
    scan.ts        -> TCP connect scanner ASLI (Node net) + banner grab  (BARU)
  src/preload/     -> jembatan aman renderer <-> main (http, proxy, scan)
  src/shared/      -> dipakai bareng main & renderer:
    http.ts        -> tipe HTTP + scope gate host (hostInScope)
    proxy.ts       -> tipe event proxy
    scan.ts        -> parse target CIDR/range, daftar port, ipInScope      (BARU)
    rules.ts       -> Rule Engine: template data-driven + matcher + CVE    (BARU)
  src/renderer/src/
    pages/web/     -> Web Security Suite (Proxy, Repeater, Intruder, Target,
                      Decoder, Comparer, Sequencer, BrowserSim)
    pages/         -> Dashboard, NetworkScanner (REAL), RuleEngine (BARU),
                      Vulnerabilities, ThreatMonitor, Firewall, Reports, Settings
    components/    -> Sidebar, TopBar, ThemeToggle, ScopeBar, ContextMenu, Crest,
                      icons, ui
    data/          -> mock.ts, burp.ts (data simulasi)
    store/         -> store.ts (settings+persist), transfer.ts (send-to bus),
                      findings.ts (store temuan Rule Engine)               (BARU)
    lib/http.ts    -> parse raw request, curl, sendLive


4. STATUS PER-MODUL (jujur: REAL vs MOCK)
--------------------------------------------------------------------------------
== WEB SECURITY SUITE (SELESAI / REAL) ==
  [DONE] Proxy        : Forward proxy ASLI + HTTPS MITM (dekripsi TLS).
                        - Start di 127.0.0.1:8080, Intercept Forward/Drop/Edit
                        - Open Browser (browser asli lewat proxy, auto-trust CA)
                        - Export CA (buat browser eksternal)
                        - HTTP History live + Inspector
                        - Klik kanan baris: Send to Repeater/Intruder, Copy URL,
                          Copy as curl, Inspect
  [DONE] Repeater     : Live (kirim HTTP asli) + Simulation
  [DONE] Intruder     : Live (serang payload asli) + Simulation
  [DONE] Target/Site  : Live content discovery (fuzzing path asli) + sim map
                        + klik kanan: Send to Repeater/Intruder
  [DONE] Decoder      : URL/Base64/Hex/HTML/ASCII encode-decode (offline, REAL)
  [DONE] Comparer     : Diff dua response (LCS, offline, REAL)
  [DONE] Sequencer    : Analisa entropi token (hitungan REAL, token masih sampel)
  [DONE] Scope gate   : semua Live digerbang host berizin

== OPERATIONS (SEBAGIAN REAL) ==
  [DONE] Network Scanner  : TCP connect scan ASLI (Node net), scope-gated.
                            - Target IP / CIDR / range / list, parse otomatis
                            - Profile Quick/Standard/Deep (deep = banner/versi)
                            - open/closed/filtered nyata, progress streaming,
                              bisa di-Stop (cancel); + mode Simulation (mock lama)
                            - hasil otomatis difeed ke Rule Engine
  [DONE] Vulnerabilities  : toggle Live (temuan Rule Engine, Confirmed/Suspected
                            + bukti + CVE) / Demo catalog (mock lama tetap ada)
  [MOCK] Dashboard        : statistik & grafik dari data palsu
  [MOCK] Threat Monitor   : feed event simulasi (boleh tetap demo)
  [MOCK] Firewall Rules   : editor rule lokal (tak ngaruh ke firewall asli)

== ANALYSIS (MASIH MOCK) ==
  [MOCK] Reports          : rangkuman dari data palsu, export .txt/.json
                            -> TODO: laporan dari temuan ASLI + PDF + Bahasa Indo

== DETECTION (DASAR JADI) ==
  [DONE] Rule Engine      : engine ala-Nuclei, template sebagai DATA (27 template).
                            - Matcher: status/word/regex/time, kombinasi and/or
                            - Pasif: makan hasil Network Scanner (port/banner->CVE)
                              + respons Proxy (header hilang, cookie, error SQL)
                            - Aktif (oracle): kirim GET /.git/config, /.env, dll
                              lewat HTTP sender scope-gated -> Confirmed + bukti
                            - Keyakinan jujur: Confirmed (teramati) vs Suspected
                            - Halaman Detection: library template + active checks
                            -> TODO: tambah template, oracle boolean/time/OOB,

6. CATATAN PENTING
--------------------------------------------------------------------------------
  - Installer belum DI-SIGN -> SmartScreen muncul sekali, klik "Run anyway".
    Antivirus kadang curiga (wajar untuk tool proxy/MITM) -> whitelist.
  - Proxy dengerin di 127.0.0.1 saja. Saat Start/Open Browser, Windows Firewall
    bisa minta izin -> Allow.
  - Mode LIVE (nembak target asli) WAJIB isi Scope dulu. Tanpa itu ditolak.
  - Open Browser: kalau Intercept ON, halaman "nahan" nunggu di-Forward
    (app otomatis maju minta Forward). Kalau mau browsing santai, matikan
    Intercept dulu.
  - HTTPS di browser eksternal butuh "Export CA" lalu di-trust di OS/browser.
    Open Browser bawaan Interu sudah auto-trust (langsung kebaca).
  - Semua data di modul MOCK = demo, bukan aktivitas sistem beneran.
